# 公考倒计时（Civil Service Examination Countdown）

一款在 iPhone / iPad 上可直接运行的 **国考 / 省考 / 各省选调 报名与考试倒计时** 应用。

- 原生 HTML/CSS/JS，无任何构建步骤，纯静态站点
- 支持 **PWA 离线运行**：在 Safari 中打开后「添加到主屏幕」，即可像原生 App 一样全屏使用（离线也能看倒计时）
- 内置 2027 届考试时间（含已公布公告与按规律整理的预计时间，均标注数据来源），所有条目可在应用内**添加 / 编辑 / 删除**，数据保存在本机
- 实时倒计时（天 / 时 / 分 / 秒）、报名窗口进度条、报名状态印章（未开始 / 报名中 / 已截止）
- 可选**考试提醒**：报名开始、报名截止、考试前 3 天 / 1 天 / 当天触发系统通知
- 深色模式跟随系统

## 在 iPhone / iPad 上安装

1. 用 **Safari** 打开应用地址（部署后见下方「部署」一节）
2. 点击底部 **分享按钮**（方框 + 向上箭头）
3. 选择 **「添加到主屏幕」**，确认添加
4. 从主屏幕点击「公考倒计时」图标即可全屏使用，离线可用

> 注意：iOS 上 Web 通知仅对**已添加到主屏幕**的 PWA 生效，且需在应用内点击右上角铃铛开启权限。iOS 后台不常驻，提醒在打开应用时触发。

## 本地运行

```bash
# 方式一：直接双击 index.html 打开
# 方式二：本地起一个静态服务（推荐，Service Worker 需在 http(s) 环境下注册）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 部署到 GitHub Pages（推荐）

1. 在仓库页面进入 **Settings → Pages**
2. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`
3. 保存后等待约 1 分钟，即可通过 `https://jijihuanhuan.github.io/Civil-Service-Examination/` 访问
4. 用 iPhone 的 Safari 打开该地址，按上文「添加到主屏幕」

## 项目结构

```
Civil-Service-Examination/
├── index.html            # 应用入口（单页）
├── css/style.css         # 样式（亮 / 暗双主题）
├── js/data.js            # 内置考试数据（可编辑，含来源）
├── js/app.js             # 应用逻辑（倒计时 / 表单 / 通知）
├── manifest.webmanifest  # PWA 清单
├── sw.js                 # Service Worker（离线缓存）
└── icons/                # 应用图标
```

## 自定义与二次开发

- **修改内置时间**：编辑 `js/data.js`，或直接在应用内添加 / 编辑 / 删除条目（会覆盖内置数据并保存在浏览器本地）
- **清除本地数据**：在应用内删除对应条目；或清除 Safari 该站点数据后重新打开
- 纯原生实现，无框架、无构建工具、无外部依赖，可直接按需改造
